# ThePrompt

**Делись идеями. Создавай больше.**

Социальная платформа для обмена промптами к нейросетям — ChatGPT, Claude,
Gemini, Midjourney, DALL·E, Stable Diffusion и другим. Логика взаимодействия
построена по образцу X/Twitter: лента по центру, панели слева и справа, лайки,
треды, репосты, сохранённое и подписки — но всё заточено под публикацию
и обсуждение промптов.

Интерфейс — тёмный «AI community dashboard»: палитра `#151515 / #1A1A19 /
#111111`, акцент `#1683FF → #006DFF`, шрифт Inter, скругления 16–20px.

## Быстрый старт

```bash
npm install
cp .env.example .env     # необязательно: без него всё работает в демо-режиме
npm run seed             # демо-пользователи и промпты (необязательно)
npm start                # http://localhost:3000
```

Требуется **Node.js 22.5+** — используется встроенный модуль `node:sqlite`,
поэтому нативные зависимости компилировать не нужно.

### Как войти

Пароля нет: вход по одноразовому коду из письма.

* **Если SMTP не настроен** (по умолчанию) — код печатается в консоль сервера
  и подставляется в форму автоматически. Приложением можно пользоваться сразу.
* **Если настроен SMTP** — код уходит письмом, в ответе API его нет.

После `npm run seed` доступны аккаунты `admin@theprompt.dev` (администратор),
`nika@theprompt.dev`, `dev@theprompt.dev`, `art@theprompt.dev`.

### Кто становится администратором

* Если в `.env` заполнен `ADMIN_EMAILS` — все перечисленные адреса получают
  роль `admin` при входе.
* Если список пуст — админом становится первый зарегистрированный пользователь.

## Возможности

**Регистрация и вход**
* Регистрация по email, одноразовый код (OTP) на почту, без паролей.
* Ограничение частоты запросов, срок жизни кода 10 минут, лимит попыток ввода.
* Второй шаг — никнейм и отображаемое имя с проверкой занятости на лету.

**Лента**
* Вкладки «Свежее», «Популярное», «Подписки».
* Фильтры по модели ИИ, уровню сложности и категории; сортировка «свежее /
  популярное / обсуждаемое»; поиск; бесконечная прокрутка.

**Публикация промпта**
* Заголовок, текст промпта, модель ИИ и её точная версия (GPT-5.1,
  Midjourney v6.1…), уровень, категория, теги, описание и пример результата
  текстом или изображением.
* Кнопка копирования — прямо в блоке промпта на карточке.
* Опрос к сообществу: вопрос и до четырёх вариантов, один голос на человека,
  голос можно перенести на другой вариант.

**Взаимодействие**
* Лайки, комментарии с вложенными ответами (треды), репосты, сохранённое
  и жалобы с выбором причины.
* Подписки на авторов и отдельная лента «Подписки».

**Профиль**
* Аватар и баннер с загрузкой изображений, имя, никнейм, био.
* Вкладки «Промпты и репосты», «Понравилось» и приватная «Сохранённое».
* Счётчики публикаций, подписчиков, подписок, лайков и сохранённого.

**Уведомления и сообщения**
* «Уведомления» — отклики на ваши промпты: лайки, репосты, ответы, подписки.
* «Сообщения» — внутренняя переписка платформы: решения модерации, системные
  письма и уведомления о новых жалобах для администраторов.

**Админ-панель** (`/admin`, только для роли `admin`)
* Жалобы: кто пожаловался, на какой пост, причина, дата и комментарий.
* Действия: открыть пост, удалить и восстановить, предупредить автора,
  заблокировать и разблокировать, отклонить жалобу.
* Вкладки «Новые / Обработанные / Отклонённые», список пользователей, статистика.

**Оформление**
* Тёмная тема — основной режим; светлая доступна переключателем в правой панели
  и в настройках. Выбор хранится в аккаунте и в `localStorage`, применяется
  до первой отрисовки (без «вспышки»).
* Адаптив: три колонки на десктопе, свёрнутая панель на планшете, нижняя
  навигация и кнопка публикации на мобильном.
* `Ctrl/Cmd + K` — переход в поиск.

**Eduardo — помощник по промптам**
Локальный конструктор: собирает каркас промпта по структуре
«роль → задача → формат → ограничения» и открывает композер с заготовкой.
К нейросети не обращается и ключей не требует.

## Тесты

```bash
npm test
```

37 сквозных проверок поверх реального HTTP-сервера и отдельной временной базы:
регистрация по OTP, публикация и редактирование промптов, заголовки и категории,
лайки, треды комментариев, репосты, закладки, опросы и голосование, подписки
и лента подписок, фильтры, сортировка, поиск, пагинация, жалобы, разделение
уведомлений и сообщений, все сценарии админ-панели, защита от CSRF.

Отдельно лежит браузерный сценарий `tests/ui.mjs` (Playwright) — 22 проверки
интерфейса: обе темы, копирование промпта, лента и фильтры, публикация,
лайки и комментарии, закладки, опрос с голосованием, жалоба, админ-панель,
«Сообщения», помощник Eduardo, статические страницы, `Ctrl+K` и мобильная
вёрстка. Он не входит в `npm test`, потому что требует браузера:

```bash
npm i -D playwright && npx playwright install chromium
npm run seed && npm start        # в отдельном терминале
node tests/ui.mjs
```

## Переменные окружения

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | порт HTTP-сервера | `3000` |
| `NODE_ENV` | режим работы | `development` |
| `SESSION_SECRET` | секрет сессий | случайный при старте |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_SECURE` | параметры SMTP | не заданы → демо-режим |
| `SMTP_USER` / `SMTP_PASS` | авторизация SMTP | пусто |
| `MAIL_FROM` | отправитель писем | `ThePrompt <no-reply@theprompt.local>` |
| `ADMIN_EMAILS` | админские адреса через запятую | пусто |
| `DB_FILE` | путь к файлу SQLite | `data/theprompt.db` |

## Безопасность

* Сессии — httpOnly-куки со случайным токеном, `SameSite=Lax`, срок 30 дней.
* Мутирующие запросы требуют заголовок `X-Requested-With` (защита от CSRF).
* Коды подтверждения хранятся только в виде SHA-256 хеша, сравнение —
  с постоянным временем; действуют ограничения по частоте и числу попыток.
* Пользовательский текст попадает в DOM только через `textContent`,
  разметка из данных не собирается.
* Загрузки — только изображения до 5 МБ, имена файлов генерирует сервер.
* Блокировка пользователя закрывает все его сессии и запрещает повторный вход.
* Сохранённое приватно: чужую вкладку «Сохранённое» API не отдаёт.

## Заметки по реализации

* Стек — Node.js + Express + SQLite и ванильный SPA на ES-модулях без сборщика.
  Дизайн-спецификация предполагала React/Next.js/Tailwind; проект остался
  на рабочем бэкенде без шага сборки, а визуальная часть спецификации выполнена
  полностью.
* Иконки и плитки моделей — собственные инлайновые SVG. Логотипы брендов
  не воспроизводятся: у каждой модели свой цвет и абстрактный знак.
* Счётчики в правой панели показывают реальные числа из базы, а не витринные.
* SQLite-функция `lower()` работает только с ASCII, поэтому для поиска
  на кириллице зарегистрирована собственная функция `ulower()`.
* Элемент ленты — пост или репост (`type: 'post' | 'repost'`); лента подписок
  собирается через `UNION ALL`.
* Удаление постов и комментариев мягкое (`deleted_at`): модератор может
  восстановить публикацию, а история жалоб остаётся целой.
* Схема обновляется догоняющими миграциями (`ALTER TABLE ... ADD COLUMN`),
  поэтому база из предыдущей версии продолжает работать.
