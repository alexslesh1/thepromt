# PromptShare

Социальная сеть для обмена промтами к нейросетям — ChatGPT, Claude, Gemini,
Midjourney, DALL·E, Stable Diffusion и другим. Логика взаимодействия построена
по образцу Twitter/X: лента по центру, боковые меню слева и справа, лайки,
комментарии-треды, репосты и подписки — но всё заточено под публикацию
и обсуждение промтов.

<p align="center">
  <em>Node.js + Express + SQLite на бэкенде, ванильный ES-модульный SPA на фронте.
  Никаких сборщиков — <code>npm start</code> и всё работает.</em>
</p>

## Быстрый старт

```bash
npm install
cp .env.example .env     # необязательно: без него всё работает в демо-режиме
npm run seed             # демо-пользователи и промты (необязательно)
npm start                # http://localhost:3000
```

Требуется **Node.js 22.5+** — используется встроенный модуль `node:sqlite`,
поэтому нативные зависимости компилировать не нужно.

### Как войти

Пароля нет: вход по одноразовому коду из письма.

* **Если SMTP не настроен** (по умолчанию) — код печатается в консоль сервера
  и подставляется в форму автоматически. Так можно пользоваться приложением
  сразу, без почтового сервера.
* **Если настроен SMTP** — код уходит письмом, в ответе API его нет.

После сид-данных доступны аккаунты `admin@promptshare.dev` (администратор),
`nika@promptshare.dev`, `dev@promptshare.dev`, `art@promptshare.dev`.

### Кто становится администратором

* Если в `.env` заполнен `ADMIN_EMAILS` — все перечисленные адреса получают
  роль `admin` при входе.
* Если список пуст — админом становится первый зарегистрированный пользователь.

## Что умеет

**Регистрация и вход**
* Регистрация по email, одноразовый код (OTP) на почту, без паролей.
* Ограничение частоты запросов кода, срок жизни 10 минут, лимит попыток ввода.
* Второй шаг регистрации — никнейм и отображаемое имя с проверкой занятости.

**Лента**
* Вкладки «Свежее» (по времени), «Популярное» (по активности) и «Подписки».
* Бесконечная прокрутка, фильтры по модели ИИ и уровню сложности, поиск.

**Публикация промта**
* Текст промта, модель ИИ из списка + точная версия (GPT-5.1, Midjourney v6.1…),
  уровень (новичок / средний / продвинутый), теги, краткое описание,
  пример результата текстом или картинкой.
* Кнопка **«Копировать промт»** прямо на карточке поста.

**Взаимодействие**
* Лайки со счётчиком, комментарии с вложенными ответами (треды), репосты,
  жалобы с выбором причины.

**Профиль**
* Аватар и баннер с загрузкой изображений, имя, никнейм, био.
* Лента собственных промтов и репостов, вкладка «Понравилось».
* Счётчики постов, подписчиков, подписок и лайков; подписка на автора.

**Админ-панель** (`/admin`, только для роли `admin`)
* Список жалоб: кто пожаловался, на какой пост, причина, дата, комментарий.
* Действия: открыть пост, удалить пост (и восстановить), предупредить автора,
  заблокировать/разблокировать автора, отклонить жалобу.
* Вкладки «Новые / Обработанные / Отклонённые», список пользователей, статистика.
* О новых жалобах админ узнаёт из внутренних уведомлений на сайте.

**Оформление**
* Тёмная и светлая темы с переключателем; выбор хранится в аккаунте
  и в `localStorage`, применяется до первой отрисовки (без «вспышки»).
* Адаптивная вёрстка: три колонки на десктопе, нижняя навигация и кнопка
  публикации на мобильном.

## Тесты

```bash
npm test
```

27 сквозных проверок поверх реального HTTP-сервера и отдельной временной базы:
регистрация по OTP, публикация и редактирование промтов, лайки, треды
комментариев, репосты, подписки и лента подписок, фильтры и поиск, пагинация,
жалобы, все сценарии админ-панели (удаление и восстановление поста,
предупреждение и блокировка автора, отклонение жалобы), защита от CSRF.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | порт HTTP-сервера | `3000` |
| `NODE_ENV` | режим работы | `development` |
| `SESSION_SECRET` | секрет сессий | случайный при старте |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_SECURE` | параметры SMTP | не заданы → демо-режим |
| `SMTP_USER` / `SMTP_PASS` | авторизация SMTP | пусто |
| `MAIL_FROM` | отправитель писем | `PromptShare <no-reply@promptshare.local>` |
| `ADMIN_EMAILS` | админские адреса через запятую | пусто |
| `DB_FILE` | путь к файлу SQLite | `data/promptshare.db` |

## Безопасность

* Сессии — httpOnly-куки со случайным токеном, `SameSite=Lax`, срок 30 дней.
* Мутирующие запросы требуют заголовок `X-Requested-With` (защита от CSRF).
* Коды подтверждения хранятся только в виде SHA-256 хеша, сравнение —
  с постоянным временем; действуют ограничения по частоте и числу попыток.
* Пользовательский текст попадает в DOM только через `textContent`,
  разметка из данных не собирается.
* Загрузки — только изображения до 5 МБ, имена файлов генерируются сервером.
* Блокировка пользователя закрывает все его сессии и запрещает повторный вход.

## Заметки по реализации

* SQLite-функция `lower()` работает только с ASCII, поэтому для поиска
  на кириллице зарегистрирована собственная функция `ulower()`.
* Пагинация ленты — offset-based, элемент ленты может быть постом или репостом
  (`type: 'post' | 'repost'`), лента подписок собирается через `UNION ALL`.
* Удаление постов и комментариев — мягкое (`deleted_at`), чтобы модератор мог
  восстановить публикацию, а история жалоб оставалась целой.
